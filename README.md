# MPT Autopilot

An end-to-end automation suite for [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo):
generate short-video ideas, render them, tag them, and upload them — from a single repository.

> This repository merges four previously separate tools:
> `shorts-pilot`, `mpt-batch`, `hashtag-enricher`, and `yt-shorts-uploader`.

Full documentation is being assembled; see `docs/` for per-stage guides.
